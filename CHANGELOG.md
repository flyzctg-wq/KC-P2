# Changelog

All notable changes to the Kunjachaya Club project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.3.0] - 2026-08-23
### Added
- Interactive Kunjachaya Residential Area Google Map (`CommunityMap.jsx`) with live embedding.
- Exact GPS coordinates: `22.3810056, 91.8165975` (Bayezid Bostami Road, 2 No. Jalalabad Ward, Chattogram).
- Roadmap and Satellite view toggles.
- Google Maps turn-by-turn navigation link and one-tap coordinate copy.
- Integrated into Resident Home, Emergency Hotlines, and Admin Dashboard.

## [1.2.0] - 2026-08-23
### Added
- Official Letter Pad template for Invoice and Money Receipt vouchers (`InvoiceReceiptModal.jsx`).
- Printable A4 layout with letterhead artwork, dynamic stamps (`PAID` / `DUE`), and executive signatures.
- Direct PDF/HTML voucher download and WhatsApp receipt messenger.
- Integrated into Admin Dues, Payment History ledger, and Resident Dues.

## [1.1.0] - 2026-08-23
### Changed
- Comprehensive dark mode contrast and color hierarchy overhaul across all components.
- Added live WebRTC camera capture modal in user profile photo upload.
- Added passport oval face guide and front/rear camera flip.

## [1.0.0] - 2026-08-23
### Added
- Initial bilingual release for Android APK and Web Platform.
- Complete documentation and bilingual User Manual (`USER_MANUAL.md`).
- Support for 15 Founding Members (`001`–`015`).
